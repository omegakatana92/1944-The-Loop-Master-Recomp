# 1944: The Loop Master — Recomp

A native PC port of **1944: The Loop Master**, the 2000 Capcom arcade
vertical-scrolling shooter developed by Raizing (Eighting) and published by
Capcom for the CP System II board. Its 68000 and Z80 programs are translated
ahead of time into C++ by [cps2recomp](https://github.com/tmcleroy/cps2recomp),
and run on a small machine written for it — no emulator, and no game data in
this repository.

Two players fly together as the P-38 Lightning or the A6M Zero through fifteen
stages of WWII, with the series' charge-and-overheat shot and side fighters.
This is a work in progress.

The port reads your own **1944: The Loop Master** ROM set (the MAME set `1944`,
Europe 000620) — nothing else is needed, and the set's key is used on the fly,
as the board does.
